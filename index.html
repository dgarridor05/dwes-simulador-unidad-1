Síntesis imprescindible de conceptos, tablas de directivas, acrónimos y configuraciones de examen.

1. Directivas Clave en php.ini

Directiva Descripción y Objetivo Valor / Ejemplo Recomendado Detalle de Examen
short_open_tag Habilita o deshabilita delimitadores cortos <? y ?>. Off Evita conflictos con la cabecera estándar de documentos XML (<?xml ...?>).
max_execution_time Tiempo máximo en segundos que puede durar la ejecución de un script. 30 (segundos) Evita bloqueos de servidor por bucles infinitos o fallos en el código.
error_reporting Determina qué nivel de errores, advertencias y avisos se mostrarán. E_ALL & ~E_NOTICE Muestra todos los errores menos avisos leves (operador ~ niega el bit).
file_uploads Permite o prohíbe la subida de archivos al servidor mediante HTTP. On / Off Booleano de activación general para formularios con enctype="multipart/form-data".
upload_max_filesize Límite máximo permitido para el tamaño de cada archivo subido individualmente. 1M, 2M... Si el archivo supera este valor, PHP abortará su recepción.

2. Acrónimos y Tecnologías de Servidor

Sigla / Término Significado Completo Función Principal y Observaciones
XAMPP X (Multiplataforma) + Apache + MySQL/MariaDB + PHP + Perl Paquete integrado todo-en-uno para desplegar un entorno de desarrollo completo.
CGI Common Gateway Interface Estándar clásico que permite ejecutar programas en cualquier lenguaje (C, Perl, etc.). Inconveniente: crea un nuevo proceso por petición.
WSGI Web Server Gateway Interface Estándar actual para conectar servidores web (Apache/Nginx como proxy inverso) con aplicaciones Python tras quedar descontinuado mod_python.
EJB Enterprise JavaBeans (Jakarta EE) Componentes que encapsulan la lógica de negocio en aplicaciones empresariales Java.
SPA Single Page Application Carga una única vez; no recarga la página completa; actualiza fragmentos con AJAX/REST consumiendo JSON de forma reactiva.
DocumentRoot Directorio raíz de Apache (htdocs) Ruta base donde Apache busca archivos web. Si falta index.php, se activa el listado de directorios (directory listing).

3. Comparativa de Modelos de Ejecución de Lenguajes

Modelo Ejemplos Ventajas Inconvenientes
Scripting / Guiones PHP, Python, Perl, ASP clásico Gran portabilidad, texto plano, cambios visibles al instante sin recompilar. Menor rendimiento: cada petición es reinterpretada desde el código fuente.
Compilados a Código Máquina C, C++ Velocidad y rendimiento de ejecución extremos. Poca portabilidad (requiere recompilación por SO) y poca integración web tradicional (crea proceso vía CGI).
Código Intermedio (Bytecode) Java (Jakarta EE, Servlets), ASP.NET (.NET) Equilibrio rendimiento y portabilidad, reutilización de procesos, optimización mediante compilación en caliente JIT (Just-In-Time). Requiere máquina virtual o plataforma específica (JVM, .NET CLR).
